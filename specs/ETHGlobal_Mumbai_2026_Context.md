## 5. Rules, submission, judging, video

### Core rules that can disqualify
- **Start fresh:** all project-specific work begins after Thu 9:00 PM. Public libraries and starter kits are fine; be transparent.
- **Version control:** use git throughout. Large single commits or missing history may be disqualified. 1inch and Whitechain repeat this explicitly.
- **Include everything:** submission includes a GitHub repo, Figma files or equivalent. Clearly separate new work from reused work.
- **Code of conduct:** harassment can lead to disqualification. Report to incidents@ethglobal.com.
- **Partner limit:** up to three sponsors per project.

### AI tools policy
Generally allowed, with three conditions:
1. **Attribution:** document where and how AI was used (which code, files or assets). Arkiv also asks for this in the README.
2. **Involvement:** AI should assist, not build the entire project. Submissions relying entirely on AI may be ineligible for partner prizes or finalist consideration.
3. **Spec-driven development** (OpenSpec, Kiro, spec-kit and similar) is allowed, but all spec files, prompts and planning artifacts must be in the repo.

### How to submit
- Hacker Dashboard → Project: name it, add a category and emoji. Teammates join with the team token.
- Submission form: project title, description and repo link.
- Last step: choose up to three partner prizes. A sponsor with several prizes counts as one pick, and you're eligible for all of that sponsor's prizes you qualify for.
- Partners judge **only from what you submit**, so for each pick explain how you used their tools, give feedback and add comments.
- Add a demo video (optional but strongly encouraged).

| Route | What it means |
| --- | --- |
| Finalist and Partner Prizes | Present live to finalist judges and also compete for partner prizes. Optional booth visits |
| Partner Prizes only | No live finalist session. Partners judge from materials. Booth visits optional |

### Finalist judging
- Session details appear on the dashboard after submitting. Check in at the judging check-in table.
- **7 minutes per team: 4 minutes demo, then 3 minutes questions.**
- Prepare for: what inspired the project, which tools you used and why, what challenges you solved.

| Criterion | What judges ask |
| --- | --- |
| Technicality | How complex is the problem and how sophisticated is the solution |
| Originality | A new idea, or a creative solution to an existing problem |
| Practicality | How complete and functional is it; could the audience use it today |
| Usability (UI/UX/DX) | How intuitive is it |
| WOW factor | The lasting impression, and anything unique that fits nowhere else |

Finalist prize amounts and the number of finalists are **not published** in the material I have.

### Partner judging
Based on submitted materials. Booth visits are optional. Partner winners are announced at the closing ceremony (Sat 3:30 PM). Sponsors don't publish scoring.

### World ($7,500)

Proofs at the event are mocked with fake identities.

### 1inch ($5,000)

**What it is.** A network of DeFi protocols known for its DEX aggregator (launched 2019). **Aqua** is a shared-liquidity layer: liquidity providers keep tokens in their own wallet and give Aqua an allowance, then commit "virtual balances" to many strategies at once. A strategy is a SwapVM program (an ordered sequence of opcodes and instructions executed at swap time). It is stored as opaque bytes and identified by (maker, app, strategyHash); once shipped it is immutable (dock and ship again to change it). `ship()` starts a strategy; `dock()` stops it with no token movement. The router serves three strategy types: `xyc`, `concentrated` and `pegged`. At launch, takers are gated to verified resolvers ([Aqua docs](https://business.1inch.com/portal/documentation/aqua/liquidity-layer/strategy)). The docs page I read did not list the SwapVM instructions. Workshop: Thu 5:30 PM, Workshop Room 2.

**Build an Aqua App: $5,000** (1st $2,500, 2nd $1,500, 3rd $1,000). Create a custom Aqua app implementing a sophisticated DeFi position. With SwapVM you can modify opcodes and define your own instructions. Demonstrate final positions through test scripts or a UI. Projects using SwapVM score higher.
- Use official Aqua/SwapVM contracts (redeploying a modified SwapVM is allowed).
- Show onchain token transfers in the final demo (local forks are fine).
- Proper git history; no single-commit entries on the final day.
- Links: github.com/1inch/aqua, github.com/1inch/swap-vm, the Aqua SDK in 1inch/sdks, the Aqua and SwapVM whitepapers.

### 0G ($12,000)

**What it is.** A stack for AI onchain: Chain (EVM L1), Storage, Compute (inference, training, verifiable computation) and DA ([0G docs](https://docs.0g.ai/intro)). **Private Computer** is one OpenAI-compatible API for 100+ models with verified runs. Every team gets compute credits. Workshop: Thu 3:30 PM, Workshop Room 1.

**Trust tiers** ([privacy docs](https://docs.0g.ai/developer-hub/building-on-0g/compute-network/router/privacy)):
- The Router keeps no prompt or completion content; it retains only billing and usage metadata (request ID, wallet, model, provider, token counts, trust tier, cost, timestamp).
- **`private` tier (sealed inference):** only TeeML providers; the model runs in an Intel TDX enclave with TEE-enabled GPUs; the prompt enters encrypted and the response is signed inside the enclave; each enclave publishes a hardware attestation checkable with dstack. Pinned per API key or per request (`X-0G-Provider-Trust-Mode: private`). If no TeeML provider is available, the request returns 503 and does not fall back.
- **`verified` tier (TeeML and TeeTLS):** the response provably came from the real model; with TeeTLS the upstream provider still processes the prompt under its own policy.
- **`standard` tier:** no attestation or signed proof.
- Without a pinned trust mode, any provider can serve the request. `private` depends on TeeML supply, so 503s can be transient. Provider-side retention for TeeML is not described.
- **UNVERIFIED:** 0G Storage's permanence or retention terms (I could not find a published guarantee).

**Build with 0G Private Computer: $5,000** (1st $2,500, 2nd $1,500, 3rd $1,000). Build a consumer app where AI on 0G is the product, something people open and come back to. Image, video and voice apps are welcome. Models include seedream, hy-image, z-image (image), seedance, minimax-h3 (video), whisper-large-v3 (speech), qwen omni and qwen vision (multimodal) and 0gm-1.0 (0G native).

- **Not wanted:** generic chat wrappers, or apps where the AI call could be removed unnoticed.
- **Must show:** inference on 0G Private Computer in the main flow with request IDs; a working app a judge can try with a reason to return tomorrow; one sentence on what breaks without 0G; for the bonus, a user signing in with a 0G account and their credit balance dropping.

**Physical AI: Agents with a Body: $5,000** (1st $2,500, 2nd $1,500, best build on real hardware $1,000). A robot, drone, wearable or pocket device whose decisions run on 0G. Simulation is eligible for every prize. 0G is the brain, not the spinal cord: motion stays on the device while 0G decides at checkpoints and keeps the record.

### Hedera ($13,500)

**What it is.** An EVM chain with SDKs for JavaScript, Java, Python, Rust, Go and Swift, and native services (HTS tokens, HCS messaging, scheduled transactions). Workshop: Thu 3:30 PM, Workshop Room 2 (Hedera x Claude Code).
