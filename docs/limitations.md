# Limitations (stub; final text from specs/Bharosa_Build_Spec_v3.md §18)
- The courier is simulated. Release depends on the buyer's code, not courier data; "handover refused" comes from our courier key.
- Quality disputes are decided by a team-run arbiter.
- Handle proof is a staff-checked bio code (tier 1).
- World proofs are validated by our backend; simulator credentials are not real-world identity.
- Reviews are created by our attestor then transferred to the buyer: we can refuse to write a review, but can't edit one afterwards.
- Everything on-chain is public: seller volumes and buyer wallets can be linked.
- Test USDT has no value; real rupee payments need a licensed partner.
